# Simulador de Gráficos de Funções

Projeto desenvolvido no Visual Studio 2022 com o objetivo de visualizar graficamente diferentes tipos de funções matemáticas.

## Funcionalidades

O programa permite gerar gráficos de:

- Função afim
- Função quadrática
- Função exponencial

O usuário informa os parâmetros da função e o programa realiza os cálculos necessários para gerar sua representação gráfica.

## Objetivo

O projeto foi desenvolvido no final de 2025 como uma forma de aplicar conceitos de programação e matemática em uma aplicação prática.

Foi um dos meus primeiros projetos envolvendo geração de gráficos e manipulação de funções matemáticas.

## Tecnologias utilizadas

- Visual Studio 2022
- C#


## Como executar

1. Clone o repositório:

git clone https://github.com/miguelcadev/Falculo.git

2. Abra o arquivo `.sln` no Visual Studio 2022.

3. Execute o projeto.
